# Media Content Matching Tool

## Overview
A VBA-based automation framework developed to improve media content validation and reporting accuracy across OTT and broadcast datasets. The tool automates title matching, metadata validation, platform extraction, and reporting discrepancy identification, significantly reducing manual review effort.

## Key Features
- Content title cleaning and normalization
- Stopword removal and word stemming
- Quoted title extraction
- Platform and channel extraction
- Fuzzy title matching and substring matching
- Match score calculation
- Automated classification:
  - Matched
  - Needs Review
  - Low Match
  - No Match
- Reporting discrepancy identification

## Technologies Used
- Excel VBA
- Data Validation
- Metadata Processing
- Media Analytics
- Reporting Automation

## Business Impact
- Reduced manual validation effort
- Improved content metadata accuracy
- Accelerated reporting workflows
- Enhanced identification of reporting discrepancies
- Improved consistency in content reconciliation processes

## Use Case
This tool was designed to support media data operations by automating the validation and reconciliation of content titles across multiple datasets, helping identify mismatches, metadata issues, and reporting inconsistencies efficiently.
